# Initial Submission Release Notes

This is the initial PubFi Plugin submission candidate.

PubFi lets users discover and inspect exact crypto-data capabilities, then run selected data
queries through an existing PubFi Account/OAuth connection. The package contains one workflow skill
and uses the existing universal MCP root. It does not expose payment, checkout, Credit purchase,
wallet, transfer, trade, investment, or accountless payment actions.

The reviewed Staging package acceptance used the immutable mono merge
f18409a1c08988a8b54bc8f77947696418add5af and Registry generation sequence 47. Review cases use
stable capability fixtures and assert generation and result shapes rather than dynamic provider
data.

Before public submission, use the Production universal MCP URL, complete the OpenAI Platform
publisher and domain checks, scan the final skill snapshot, and provide reviewer credentials only
through the protected portal flow. This repository does not contain connection mappings,
credentials, tokens, or private account data.
